# Clínica Bujanda — Demo de plataforma digital

Primera versión interactiva (demostración) de la plataforma integral para Clínica Bujanda — Cirugía Plástica, Buenos Aires.

**Todos los datos son ficticios. No hay cobros reales. Las imágenes son provisionales.**

## Qué incluye
- Sitio público bilingüe (ES/EN): home, tratamientos, perfil médico, Taylor Made, instalaciones, turismo médico, tienda, workshops, notas y FAQ.
- Portal del paciente: reserva con retención temporal de horario, pago de prueba con Mercado Pago, turnos, presupuestos, seguimiento y documentos.
- Portal de profesionales: capacitaciones, inscripción y pagos.
- Backend del cirujano y de la secretaria: CRM, agenda, finanzas, tienda, permisos, notificaciones, auditoría y centro SEO/GEO.

Usá el selector de **Perfil** de la barra superior para recorrer cada rol.

## Ver localmente
Abrí `index.html` en el navegador. Es un archivo autónomo (HTML + CSS + JS).

## Publicar con GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)`.
